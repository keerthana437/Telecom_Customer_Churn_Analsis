# Telecom_Customer_Churn_Analsis
Telecom Customer Churn: Key Insights  Of 5,000 customers, 13% churned (649 accounts), about $42K or 14% of revenue. Four or more service calls doubled churn (17.2% vs 8.8%). Heavy daytime users (20.3%) and international plan holders (18.2%) also churned more, and combining four or more calls with heavy daytime use reached 25.4%.
